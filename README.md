# STM32CubeMX 汉化

STM32CubeMX（实测 6.x）界面汉化——**运行时翻译（Java Agent）**，不改任何程序文件、不碰 exe、不影响功能，装好即用、一键还原。

## 怎么装？（新手照做即可）

> 全程只需三步，**不用装任何东西**。装完从桌面图标打开 STM32CubeMX 就是中文。

### 第 1 步：把这个仓库下载到电脑

在页面右上角点绿色的 **`Code`** 按钮 → 选 **`Download ZIP`** → 下载后**解压**到任意文件夹（例如桌面）。
解压后应能看到 `一键安装汉化.bat`、`工具`、`成品` 等文件。

> 提示：如果不会解压，右键压缩包 → 用系统自带的「全部解压缩」即可。

### 第 2 步：双击 `一键安装汉化.bat`

- 弹出「是否允许此应用对你的设备进行更改？」→ 点 **`是`**（写入安装目录需要管理员权限，脚本会自动请求）。
- 脚本会**自动找到** STM32CubeMX 安装目录并安装汉化；实在找不到时，会提示你粘贴安装目录
  （右键桌面 STM32CubeMX 图标 →「打开文件所在位置」→ 复制地址栏即可）。
- 看到 `[√] 汉化已安装` 即成功。

### 第 3 步：打开 STM32CubeMX

从桌面快捷方式（或开始菜单）启动，界面即为中文。

> **想还原英文**：双击 `一键还原英文.bat`（同样点一次「是」）。
> **安装时提示软件正在运行**：先完全关闭 STM32CubeMX 再双击一次。

## 常见问题

| 现象 | 原因 | 解决方法 |
|---|---|---|
| 双击 bat 弹「Windows 已保护你的电脑」 | SmartScreen 对未签名脚本的常规拦截 | 点「更多信息」→「仍要运行」 |
| 双击后窗口一闪而过 | 脚本报错退出（少见） | 右键 `一键安装汉化.bat` →「以管理员身份运行」重试；仍失败请带截图反馈 |
| 提示「未能自动找到 STM32CubeMX 安装目录」 | 安装位置非常规 | 按提示粘贴安装目录：右键桌面图标 → 打开文件所在位置 → 复制地址栏 |
| 提示「STM32CubeMX 正在运行」 | 脚本防止改配置时文件被占用 | 完全关闭 STM32CubeMX（含托盘）后重试 |
| 杀毒软件弹窗/拦截 | 脚本要写启动配置和释放 agent | 允许/信任即可；全部脚本为纯文本可自行审阅 |
| 打开还是英文界面 | agent 未加载 | 确认安装时提示 `[√] 汉化已安装` 后**重新打开**软件（不是刷新窗口） |
| 想彻底卸载汉化 | — | 双击 `一键还原英文.bat`，配置与文件全部还原，无残留 |
| 部分界面还是英文 | 词库暂未覆盖 | 属正常现象，未收录的文字**原样显示英文**；可按下方「维护词库」补充 |

### 安全说明（为什么可以放心用）
- **不改任何程序文件**：exe、jar、DLL 一律不碰；只在启动参数 `STM32CubeMX.l4j.ini` 末尾加一行 `-javaagent:`；
- agent 只替换界面**显示出来的文字**（标题/菜单/按钮/标签/提示），不触碰逻辑与数据；全程吞掉自身异常，出问题也不影响主程序；
- 安装前自动备份启动配置为 `.zhbak`，还原脚本可完全恢复原状。

## 用法（进阶）

### 安装与还原
- 双击根目录 `一键安装汉化.bat` / `一键还原英文.bat`（新手入口，自动提权、自动定位安装目录）；
- `工具\安装汉化.cmd` / `工具\还原英文.cmd` 为等价入口；
- 命令行可用 `-Root "安装目录"` 指定路径、`安装汉化.ps1 -Discover` 进入收集模式。

### 维护词库（汉化流程）
1. （可选）双击 `工具\收集未翻译.cmd`，正常使用 CubeMX 逛一圈，未翻译文字会自动记入
   `C:\ProgramData\stm32zh\发现-未翻译.tsv`；
2. 把这些文字翻译后追加进 `词库\zh.tsv`（`英文<TAB>中文`）；
3. 重新运行 `一键安装汉化.bat`（不含收集模式）；
4. 重启 CubeMX 即生效。

### 重新构建 agent

```
powershell -ExecutionPolicy Bypass -File 工具\构建.ps1
```

用 CubeMX 自带 JDK（`jre\bin\javac`）编译，输出到 `成品\`（JDK 目录自动探测，也可 `-Jdk` 指定）。源码改动后需要重新构建并重装。

## 原理（30 秒版）

STM32CubeMX 是 **Swing/AWT** 应用，界面文字**硬编码在 class 里**（没有语言包机制），主程序打包在 227 MB 的 exe 内且尾部加密——改 jar / 改 exe 都不现实。因此挂一个 9 KB 的 **Java Agent**：

```
STM32CubeMX.exe（壳）
  └─ jre\bin\javaw.exe <l4j.ini 里的参数> -classpath "STM32CubeMX.exe;anything" com.st.microxplorer.maingui.STM32CubeMX
                                     ↑
                        加一行 -javaagent:...\stm32cubemx-zh-agent.jar
```

agent 加载后，每 400 ms 在 Swing 事件线程上走一遍所有窗口：窗口标题、`JMenu`/`JMenuItem`、`AbstractButton`、`JLabel`、`JTabbedPane` 页签、`JTable` 表头、`TitledBorder` 标题、各类 tooltip —— 命中词典就替换，未命中原样保留。**只调用 `setText/setTitle` 这类显示接口**，因此不可能影响业务逻辑。

## 覆盖范围与已知限制

- **覆盖**：窗口标题、菜单栏与全部菜单项、按钮/复选框/单选框、标签、选项卡、表格表头、
  各类提示（tooltip）、分组边框标题；含 `<html>` 富文本标签的分段翻译。
- **不覆盖**（有意为之）：
  - 引脚图/时钟树等**自绘画布**上的文字（`Graphics.drawString`）——里面绝大多数是
    器件型号、引脚名、外设名等**技术名词，本就应保留英文**；
  - 下拉框/列表/表格**单元格里的数据**（如芯片型号、封装）——不翻译，避免影响数据与逻辑；
  - 用户输入框内容。
- **词库覆盖率决定汉化完整度**：v1 词库覆盖主页与常用界面（约 330 条），
  更深层对话框可用「收集模式」逐步补齐；未收录的条目**原样显示英文**，不会出现空白或乱码。
